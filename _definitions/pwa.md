A progressive web app (PWA) is a type of application software delivered through the web, built using common web technologies including HTML, CSS, JavaScript, and WebAssembly. It is intended to work on any platform that uses a standards-compliant browser, including desktop, mobile, and tablet devices. [<sup>[1]</sup>]({{page.links[0]}})
